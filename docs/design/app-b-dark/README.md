# Design do app, opção B em modo escuro (aprovado pelo André em 2026-10-08)

Mesma estrutura de `docs/design/app-b/` (a versão clara, **validada e que deve ser mantida como está**), com a paleta escura. As maquetes `.dc.html` são especificação, não rodam sozinhas. `Main` = grade, `Ficha`, `Leitor` (aba Ler), `Config`.

| Cartões / barra do topo / campos | `#FFFFFF` | `#1D201E` |
